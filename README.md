# 🎵 Lossless Music Grabber (ALAC / FLAC)

Десктопное приложение с современным темным GUI для поиска и скачивания музыки в высоком качестве (**ALAC** и **FLAC 16-bit / 24-bit Hi-Res**).

---

## ✨ Возможности

- 🔍 **Параллельный поиск по нескольким источникам**: одновременный опрос каталогов (Apple Music / ALAC, Deezer Lossless, Archive.org FLAC, открытые Lossless-зеркала, HQ Stream).
- 🎧 **Прямая интеграция с ВК Музыкой (`vk.ru/audios...`)**: загрузка ваших личных аудиозаписей и плейлистов из ВК с пакетным скачиванием в высоком качестве («⚡ Скачать ВСЁ в Hi-Res»).
- 🖼 **Стильная иконка приложения в панели задач Windows (Taskbar)**: кастомная неоновая Hi-Fi иконка.
- 🏷 **Выбор трека из списка**: карточки с оригинальной обложкой, длительностью, альбомом, годом выпуска и бейджем качества (`Hi-Res 24-bit`, `FLAC Lossless`, `ALAC Lossless`, `HQ Audio`).
- 💎 **Выбор формата сохранения**:
  - **ALAC (`.m4a`)** — Apple Lossless Audio Codec (идеально для экосистемы Apple, iPhone, iTunes/Apple Music без потерь).
  - **FLAC (`.flac`)** — Free Lossless Audio Codec (стандарт для аудиофилов, плееров FiiO, HiBy, foobar2000, VLC).
- 🖼 **Автоматическое вшивание метаданных и обложек**: исполнитель, название, альбом, год, номер трека и встроенный арт альбома высокого разрешения.
- ⚡ **Нулевая ручная настройка**: FFmpeg встроен и подключается автоматически.
- 📂 **Удобный выбор папки сохранения** и кнопка «Открыть папку» в один клик.

---

## 🚀 Запуск программы

### Способ 1. Быстрый запуск через батник (Windows)
Просто дважды кликните по файлу:
```
run.bat
```

### Способ 2. Запуск через терминал
```bash
python app.py
```

## 📁 Структура проекта

```
d:\FLAC_SErch\
├── app.py                  # Главная точка входа приложения
├── run.bat                 # Файл запуска для Windows
├── config.py               # Сохранение настроек пользователя
├── requirements.txt        # Список зависимостей
├── core/
│   ├── models.py           # Модели данных треков и уровней качества
│   ├── audio.py            # FFmpeg конвертация в ALAC (.m4a) и FLAC (.flac)
│   ├── metadata.py         # Вшивание тегов ID3/Vorbis/MP4 и обложек (mutagen)
│   └── engine.py           # Многопоточный оркестратор поиска и загрузок
├── sources/
│   ├── base.py             # Базовый интерфейс провайдера
│   ├── music_search_resolver.py # Apple Music / ALAC источник
│   ├── deezer_source.py    # Deezer Hi-Fi источник
│   ├── archive_source.py   # Archive.org FLAC 16/24-bit источник
│   ├── web_source.py       # Web Lossless зеркала
│   └── fallback_source.py  # HQ Stream fallback
└── ui/
    ├── styles.py           # Палитра и стили интерфейса
    ├── track_card.py       # Виджет карточки трека
    └── main_window.py      # Главное окно CustomTkinter
```
